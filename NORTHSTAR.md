# Github Profile North Star

## North Star

**What it is:** Github Profile is a startup/workspace project in the Noaerth operating ecosystem. <p align="center">

**Who it serves:** It serves the specific users implied by the product surface, source code, and repository documentation, with any uncertain audience kept explicit until verified.

**Core problem:** The project should solve a concrete coordination, clarity, automation, infrastructure, or user-experience gap without inflating prototype maturity.

**Differentiated approach:** Build the narrowest inspectable workflow first: clear inputs, honest labels for demo versus live capability, useful outputs, and source-backed claims.

**Enduring product direction:** Move toward a durable operating loop that captures context, structures the work or decision, produces an artifact or action, preserves what matters, and makes the next step obvious.

**Non-negotiable principles:**
- Keep claims evidence-backed and label prototype, demo, mock, seed, and live data honestly.
- Preserve user trust: no hidden data access, inflated maturity claims, or destructive automation without approval.
- Ship the narrow workflow before broad platform language.
- Make outputs inspectable, exportable, and useful without requiring belief in the pitch.
- Let the project domain shape the interface, vocabulary, and success metrics.
