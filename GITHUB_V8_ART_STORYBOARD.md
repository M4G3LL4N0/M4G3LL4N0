# GitHub V8 -- Account Art Storyboard

Every public owned repository, its purpose, its confidence, and the five to ten
animated surfaces it will receive. Written before any asset was generated so the
rollout executes a plan instead of inventing per repository.

**136 public repositories** &#183; confidence E3 125 / E2 10 / E1 1

---

## Profile -- ten major visual surfaces

The account reads as one studio that has built many distinctly different systems,
not as one README template applied a hundred and thirty times.

| # | Surface | What it represents | Motion | Geometry |
| --- | --- | --- | --- | --- |
| 1 | **DUNG30N5 hero** | the studio identity assembling from modular units | tiles lock into a grid as structure forms (12–18s) | isometric blocks + rosette |
| 2 | **computer-science terminal** | how the portfolio is operated and verified | a command executes and output resolves (16–30s) | terminal frame + output tree |
| 3 | **public systems atlas** | every public repository as a node in one field | a dependency graph resolves toward its roots (15–24s) | node graph + containment edges |
| 4 | **build / test / release pipeline** | how the portfolio is verified | tests advance and results resolve (11–18s) | stage arches + progress bars |
| 5 | **language and technology constellation** | the technical surface area | signal propagates outward from a source node (11–17s) | constellation nodes + edges |
| 6 | **systems-architecture landscape** | the dominant architectural patterns | layers slide past, showing depth (14–22s) | layered planes + module frames |
| 7 | **algorithms and data structures** | the computational structures present | an index probe walks a sorted key space (10–17s) | indexed field + probe path |
| 8 | **open-source and upstream activity** | release and commit evidence | an ordered sweep crosses the field (7–12s) | activity bars + timeline |
| 9 | **selected-project constellation** | the strongest repositories as a field | shapes tessellate a plane edge to edge (13–19s) | tessellated tiles + identity objects |
| 10 | **why-are-you-here terminal** | the closing statement | a command executes and output resolves (16–30s) | terminal frame + signature mark |

## How to read this

Each surface reveals a different facet. The hero is identity, the terminal is
operation, the architecture is construction, the state machine is behaviour, the
build surface is verification. Five images that repeat one composition is a
failure, so the duplication test compares geometry graph, motion vocabulary,
layout, colour family, timing, terminal pattern and asset sequence across every
pair of unrelated repositories.

A repository with no CLI does not get a terminal surface. A repository with no
tests does not get a test animation. What a project cannot support is omitted
rather than invented.
